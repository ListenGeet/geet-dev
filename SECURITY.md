# Security policy

## Reporting a vulnerability

Please report security issues privately through GitHub's **Report a vulnerability** feature on this repository. Do not open a public issue for an unpatched vulnerability.

Include the affected component, steps to reproduce, and the potential impact. Redact credentials, personal information and production data from reports and attachments.

The maintainers aim to acknowledge a report within seven days and share updates as the issue is investigated. Please allow time for a fix and coordinated disclosure before publishing details.

## Scope

This policy covers the code and configuration in this repository and the deployed Geet services. Third-party services are subject to their own security reporting processes.
